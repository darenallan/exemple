# Ajouter un produit — admin simplifié

Formulaire d'administration pour créer une fiche produit e-commerce : type de produit, informations, images, prix, SKU et stock, variations, statut, mise en avant, réduction, poids, marque, catégorie et livraison.

## Contenu

- `index.html`, `style.css`, `script.js` : interface statique, sans dépendance.
- `.github/workflows/deploy.yml` : publication automatique sur **GitHub Pages** à chaque push.

## Lancer

Ouvrir `index.html` dans un navigateur.
